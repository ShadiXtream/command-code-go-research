## Brief

P3.1 delivered the schema, generator, validator, and golden test. P3.2 fills `model-benchmarks.csv` with benchmark data and generates one draft file per model. Batch A covers the 13 open-weight flagship models: DeepSeek V4.1 Flash, DeepSeek V4 Flash, DeepSeek V4 Flash Fast, DeepSeek V4.1 Flash Fast, DeepSeek V4 Flash Vision, Kimi K3, Kimi K2.7 Code, GLM-5.3 Flash, GLM-5.2, Qwen3.8 Max, Qwen3.8 Max 0902, Qwen3.7 Max, and Tencent Hy4 Flash.

AA coverage is incomplete: nine of the thirteen Batch A models have no Intelligence Index on their current AA page. Evaluated dated variants are used only with an explicit `PROXY` flag; missing values stay `NE`/`NM`. LiveBench categories use the project mapping verified against the seven samples. Arena is available only for GLM-5.3 Flash in this batch; SWE-bench has no Batch A rows.

1. Add 13 Batch A rows to `Models Benchmark/data/model-benchmarks.csv` with `status: draft`.

## Risks and alternatives

- **AA coverage:** nine of thirteen models have no current index. Treating a low-effort variant as the headline would be misleading; proxies are flagged and excluded where not comparable.
- **LiveBench variants:** several rows are dated variants or Max-only evaluations. The mapping is flagged in `lb_source` and `data_quality_flags`.
- **Arena:** only GLM-5.3 Flash has a captured value (1,476, preliminary checklist). Others are `NM`.
- **SWE-bench:** no Batch A rows; all are `NE`.
- **Mapping divergence:** LiveBench’s current code routes some tasks differently from the project mapping. The project mapping is retained for sample comparability and flagged for P3.4 review.
- **Draft prose:** §§5–8 are generated scaffolds (`TBD`); Batch A needs human review before any status moves to `approved`.
